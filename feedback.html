当前版本为公开预览 0.151.0 · MVP Candidate。这表示自动候选验收已收口， 不表示 MVP 已经由真人验证。界芽公开预览不收集表单、账号或联系方式。你可以 主动前往 GitHub 查看公开部署记录或提交问题。

尚待 10～20 人真人验证

  • 首次有效操作完成率 ≥80%；
  • 十分钟完整循环完成率 ≥60%；
  • ≥60% 愿意继续创建或修改；
  • ≥70% 能说出一个直接原因；
  • 崩溃、白屏和存档丢失为零；
  • 需要口头解释的步骤不超过一个。

MVP Candidate 边界

自动验收已覆盖玩家建立三个会话时间锚、恢复旧端点并形成新分支；锚点只在 本次打开期间有效。真人指标尚未完成，因此当前仍称为 MVP Candidate， 而不是“已验证 MVP”。
